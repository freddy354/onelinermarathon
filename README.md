Entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun: one one-line comedy joke, up to 280 characters, judged head to head by an AI judge.

`main.py` writes the joke to `/output/entry.txt` (83 characters, no trailing newline) and verifies byte-for-byte that the file matches the joke.
